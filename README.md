Solmar Bay — a complete open-world crime game in the spirit of GTA 6, playable in a desktop browser from static files with no network request. A sun-soaked original city (downtown, beach, docks, park and suburbs) to explore on foot and by car, with traffic and pedestrians, cars to steal, a 5-star wanted level with police cars and foot cops, six story missions from Rosa Delgado, combat, a HUD with a live minimap, a start screen and a save that keeps your cash, missions and gold palm tokens. All city, characters, vehicles, names, story, art and sound are original — nothing from any commercial game. Built with plain canvas 2D and synthesised WebAudio, no libraries and no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Enter. Or open `game/index.html` from any static server.

Controls: WASD/arrows move and drive · mouse aim, click to shoot · E enter/exit a car · Shift run · Space brake · R reload · P pause · M mute. Progress saves automatically.
